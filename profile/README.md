## Highlights
* Bring-your-own-playlist design — no channels included or hosted by the app itself
* Program guide, favorites, and multi-screen viewing in one interface
* Works with M3U playlists, M3U URLs, and Xtream Codes logins

## Overview
IPTV Smarters Player for Windows is built around a simple job: take an IPTV subscription, playlist, or login you already have, and give it a clean, organized place to run on your PC. It doesn't provide, sell, or bundle any TV channels itself — everything you watch comes from the service or playlist you connect.

## Features
- [ ] Add a playlist through an M3U file, M3U URL, or Xtream Codes login
- [ ] View a program guide when your provider includes EPG data
- [ ] Save favorite channels for quick access
- [ ] Watch multiple streams at once in multi-screen mode
- [ ] Restrict channels or categories with a parental lock

## Getting Started
After installing, opening IPTV Smarters Player for the first time drops you into a short setup screen where you pick how to connect — M3U link, M3U file, or Xtream Codes login — and enter the details for the service you already use; once that's done the channel list loads and you're ready to start browsing and building a favorites list.
